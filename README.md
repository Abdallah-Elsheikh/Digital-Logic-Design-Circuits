# Digital Logic Design Circuits

## Overview
This repository demonstrates my understanding of **Computer Architecture** and **Hardware Logic Design**. It contains simulation projects created using **NI Multisim**, showcasing how software concepts interact with physical circuitry.

## 📂 Circuit Simulations

| Project Name | Schematic Preview | Description |
| :--- | :--- | :--- |
| **Aircraft Control System**<br>*(File: `Aircraft-Control-System.ms11`)* | <img src="circuit 2.png" width="400"> | **Complex Logic Control:** A simulation of a control system using multiple input switches (S1-S5) representing sensors. It utilizes **7408N (AND)**, **7432N (OR)**, and **7404N (NOT)** gates to drive three distinct output indicators (X1, X2, X3) based on specific logic conditions. |
| **Logic Circuit Fundamentals**<br>*(File: `Logic-Circuit-Fundamentals.ms11`)* | <img src="circuit 1.png" width="400"> | **Combinational Logic Demo:** A foundational circuit demonstrating Boolean logic. It processes four inputs using **AND gates** to feed into an **OR gate**, activating the output (X1) only when specific input pairs are active simultaneously. |
## 🛠️ Tools Used
- **Software:** NI Multisim (Circuit Design Suite)
- **Concepts:** Boolean Algebra, Combinatorial & Sequential Logic, Circuit Simulation.

## How to Run
1. Download the `.ms11` files.
2. Open them using **NI Multisim**.
3. Run the simulation (F5) to see the logic in action.
