# Digital Logic Design Circuits

## Overview
This repository demonstrates my understanding of **Computer Architecture** and **Hardware Logic Design**. It contains simulation projects created using **NI Multisim**, showcasing how software concepts interact with physical circuitry.

## 📂 Circuit Simulations

| Project Name | Schematic Preview | Description |
| :--- | :--- | :--- |
| **Aircraft Control System**<br>*(File: `Aircraft-Control-System.ms11`)* | <img src="circuit1.png" width="400"> | A simulation of an aircraft's landing gear control logic. The circuit uses combinatorial logic gates to process sensor inputs to ensure safe deployment conditions. |
| **Logic Circuit Fundamentals**<br>*(File: `Logic-Circuit-Fundamentals.ms11`)* | <img src="circuit2.png" width="400"> | A foundational digital circuit demonstrating sequential logic design. It implements a binary counter using flip-flops and logic gates to visualize state changes. |

## 🛠️ Tools Used
- **Software:** NI Multisim (Circuit Design Suite)
- **Concepts:** Boolean Algebra, Combinatorial & Sequential Logic, Circuit Simulation.

## How to Run
1. Download the `.ms11` files.
2. Open them using **NI Multisim**.
3. Run the simulation (F5) to see the logic in action.
